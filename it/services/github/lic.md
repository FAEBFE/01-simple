# GitHub: лицензия репозитория

## Цель

Определить, нужна ли репозиторию лицензия, выбрать подходящую лицензию и проверить результат.

## 1. Сначала определить необходимость лицензии

Если репозиторий публикуется без лицензии, это **не означает**, что его содержимое автоматически разрешено свободно использовать.

При отсутствии лицензии сохраняются стандартные ограничения авторского права.

Поэтому сначала определить, нужно ли явно разрешить другим:

- использовать код;
    
- изменять его;
    
- распространять;
    
- включать в другие проекты;
    
- использовать коммерчески.
    

## 2. Выбрать лицензию

[Choose a License](https://choosealicense.com/?utm_source=chatgpt.com)

Использовать сервис как отправную точку для выбора, а окончательный текст лицензии проверять по её официальному тексту и условиям.

Распространённые варианты:

```text
MIT
Apache-2.0
GPL
```

У них различаются условия использования, распространения и производных работ.

## 3. Указать лицензию при создании репозитория

При создании репозитория через веб-интерфейс можно выбрать `License`.

При создании через GitHub CLI используется:

```bash
gh repo create --public --license MIT
```

Список доступных ключей лицензий:

```bash
gh repo license list
```

GitHub CLI поддерживает параметр `--license` при создании репозитория.

## 4. Добавить лицензию в существующий репозиторий

Лицензия обычно хранится в корне репозитория в файле:

```text
LICENSE
```

Проверить наличие:

```bash
ls -l LICENSE
```

Проверить состояние Git:

```bash
git status
```

Если файл добавлен:

```bash
git add LICENSE
git commit -m "Add license"
git push
```

## 5. Проверить результат

В репозитории проверить:

```text
LICENSE
```

и отображаемую GitHub информацию о лицензии.

Также проверить, что выбранный текст лицензии соответствует намерениям проекта.

## Полезные команды

Проверить наличие лицензии:

```bash
ls -l LICENSE
```

Посмотреть начало файла:

```bash
head -n 20 LICENSE
```

Проверить состояние:

```bash
git status
```

Показать последний commit:

```bash
git log --oneline -1
```

Показать лицензии, доступные GitHub CLI:

```bash
gh repo license list
```

Открыть репозиторий:

```bash
gh repo view --web
```

## Результат

Репозиторий содержит выбранную лицензию либо осознанно публикуется без неё.

Лицензия рассматривается как самостоятельная характеристика репозитория и не смешивается с процедурой его создания и подключения.
