# Хранение вложенных файлов

Чтобы в Obsidian картинки и другие вложенные файлы автоматически сохранялись в одну специальную папку, вам нужно изменить базовые настройки приложения.

## Шаг 1. Создайте папку для картинок

1. В левой панели (проводнике файлов) Obsidian нажмите на иконку создания новой папки.
2. Назовите её, например, `Assets`, `Images` или `Вложения`.

## Шаг 2. Измените настройки вложений

1. Откройте Настройки (значок шестерёнки в левом нижнем углу или комбинация `Ctrl + ,` / `Cmd + ,`).
2. В левом меню выберите раздел Файлы и ссылки (Files and links).
3. Найдите пункт Место для вложенных файлов по умолчанию (Default location for new attachments).
4. Измените значение с «В корне хранилища» на В папке, указанной ниже (In the folder specified below).
5. В появившейся строке Путь к папке вложений (Attachment folder path) укажите имя папки, которую вы создали на Шаге 1 (например, `Assets`).

[https://obsidian.md](https://obsidian.md/ru/help/attachments)
