# nnn: переход в выбранный каталог после выхода

У `nnn` есть готовая интеграция с Bash, которая позволяет после выхода из файлового менеджера автоматически перейти в тот каталог, в котором находился `nnn`.

Это удобно, когда не хочется постоянно вручную набирать длинные пути вроде:

```text
~/mdbd/pub/FAEBFE.github.io/
```

В Arch Linux эта интеграция уже входит в пакет `nnn`:

```text
/usr/share/nnn/quitcd/quitcd.bash_sh_zsh
```

## Проверка

Установленная версия:

```bash
nnn -V
```

Пример:

```text
5.3
```

Проверить наличие интеграции:

```bash
pacman -Ql nnn | grep quitcd
```

Должно быть:

```text
nnn /usr/share/nnn/quitcd/quitcd.bash_sh_zsh
```

## Подключение к Bash

Добавить в `~/.bashrc`:

```bash
source /usr/share/nnn/quitcd/quitcd.bash_sh_zsh
```

После изменения перезапустить Bash:

```bash
exec bash
```

Теперь вместо запуска:

```bash
nnn
```

можно использовать:

```bash
n
```

`n` — функция Bash, которую предоставляет файл `quitcd.bash_sh_zsh`.

## Как это работает

Запускаем:

```bash
n
```

Открывается `nnn`.

Например, переходим:

```text
~/mdbd/pub/FAEBFE.github.io/
```

После выхода из `nnn` текущий каталог Bash автоматически меняется на выбранный каталог.

Проверить:

```bash
pwd
```

Получим:

```text
/home/faebfe/mdbd/pub/FAEBFE.github.io
```

Таким образом, вместо ручного ввода:

```bash
cd ~/mdbd/pub/FAEBFE.github.io
```

можно:

```bash
n
```

выбрать каталог в `nnn` и выйти.

## Что происходит внутри

Интеграция использует переменную:

```bash
NNN_TMPFILE
```

По умолчанию для этой интеграции используется:

```text
~/.config/nnn/.lastd
```

При выходе `nnn` сохраняет информацию о последнем каталоге, а функция `n` после завершения `nnn` читает этот файл и выполняет переход.

Саму функцию можно посмотреть:

```bash
cat /usr/share/nnn/quitcd/quitcd.bash_sh_zsh
```

Основная часть выглядит следующим образом:

```bash
export NNN_TMPFILE="${XDG_CONFIG_HOME:-$HOME/.config}/nnn/.lastd"

command nnn "$@"

[ ! -f "$NNN_TMPFILE" ] || {
    . "$NNN_TMPFILE"
    rm -f -- "$NNN_TMPFILE" > /dev/null
}
```

Поэтому это не отдельный скрипт, который пришлось писать самостоятельно, а штатная возможность `nnn`.

## Почему это удобно для `mdbd`

При работе с несколькими репозиториями и каталогами пути быстро становятся длинными:

```text
~/mdbd/clips/
~/mdbd/md/
~/mdbd/pub/
~/mdbd/pub/FAEBFE.github.io/
~/mdbd/pub/FAEBFE.github.io/_posts/
~/mdbd/pub/media/
```

`nnn` можно использовать как визуальный навигатор по этой структуре, а Bash при выходе автоматически получает выбранный каталог.

Получается простой рабочий цикл:

```text
Bash
  ↓
n
  ↓
nnn
  ↓
выбор каталога
  ↓
выход
  ↓
Bash уже находится в выбранном каталоге
```

Это не заменяет работу с путями в Bash, а просто избавляет от необходимости помнить и вручную набирать длинные пути.

## Полезные команды

Проверить версию:

```bash
nnn -V
```

Проверить установленный пакет:

```bash
pacman -Qi nnn
```

Проверить наличие Bash-интеграции:

```bash
pacman -Ql nnn | grep quitcd
```

Посмотреть её содержимое:

```bash
cat /usr/share/nnn/quitcd/quitcd.bash_sh_zsh
```

Перезапустить текущий Bash после изменения `~/.bashrc`:

```bash
exec bash
```

Запустить `nnn` с переходом в выбранный каталог после выхода:

```bash
n
```

Проверить текущий каталог:

```bash
pwd
```

## Важно

`quitcd` решает задачу **навигации по каталогам**.

Он не означает, что выбранный в `nnn` файл автоматически вставится в уже набранную команду Bash:

```bash
cp ...
```

Это отдельная задача — передача выбранного пути из файлового менеджера непосредственно в командную строку.

Для простой навигации по структуре `mdbd` штатного `quitcd` достаточно.
